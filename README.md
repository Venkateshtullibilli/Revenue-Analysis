# Power BI Revenue Analysis Dashboard

## 📊 Project Overview

This project is an interactive Revenue Analysis Dashboard developed using Microsoft Power BI. The purpose of this project is to explore revenue data, analyze monthly revenue trends, and understand revenue distribution across product categories and states.

This project is part of my practical learning journey in Data Analytics, where I am developing my skills in data visualization and business intelligence using Power BI.

## 🎯 Project Objectives

- Analyze monthly revenue trends.
- Understand revenue distribution across states.
- Compare revenue across product categories and promotions.
- Explore data using interactive slicers.
- Practice building different visualizations in Power BI.
- Learn how to present data in a meaningful and interactive format.

## 📈 Dashboard Visualizations

### 1. Column Chart
Displays revenue by product category and promotion, helping explore revenue distribution across the selected dimensions.

### 2. Pie Chart
Shows the distribution of revenue across different states, allowing comparisons between state-level contributions.

### 3. Line Chart
Visualizes monthly revenue trends to help identify changes and fluctuations over time.

### 4. Advanced Line Chart
Provides an additional view of revenue trends using the advanced chart design implemented in the report.

### 5. Interactive Slicers
Allows users to filter the report by product category and explore different segments of the data.

### 6. Additional Practice Pages
The Power BI report also includes pages for a table visual, additional advanced line charts, and a decomposition tree.
